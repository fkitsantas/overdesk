# Overdesk brand assets

| File | Use |
|---|---|
| `app-icon-macos-1024.png` | macOS app icon source (824 px tile on Apple's 1024 grid, transparent corners) |
| `app-icon-square-1024.png` | Windows / Linux icon source (full-bleed rounded tile) |
| `favicon-256.png` | Website favicon source |
| `lockup-light.png` / `lockup-dark.png` | The wordmark lockups, cut from boards 04 and 05 with their card backgrounds removed. Shown at native size (≈424×60) atop the app |
| `symbol.svg` | Vector mark in the brand gradient, for in-app and web use |
| `tray-template.svg` | Monochrome macOS menu-bar template (the system tints it) |
| `reference/` | The original brand boards: concept, lockups, palette |

The app icon and favicon are cut from the original boards. The icon tile there is
280 px, so it's sharp up to 256 px and slightly soft at 512 and 1024 px. Replace
`app-icon-*-1024.png` with a native 1024×1024 export when one exists.

**Palette:**
- Electric Indigo `#6A5CFF` (primary)
- Violet Blue `#7A3FF2`
- Teal `#14B8A6`
- Near-Black `#0B0B10`
- Near-White `#F8F9FB`
